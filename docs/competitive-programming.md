# Competitive Programming Track

## When to start

- Months 1–3: no contest requirement; build C++ and problem-solving fundamentals.
- Months 4–6: one short virtual contest per month.
- Months 7–12: two contests per month.
- Months 13–18: two to four contests per month.
- Months 19–21: up to one contest per week only if upsolving remains sustainable.
- Months 22–24: two contests per month while interview work has priority.

Suggested progression:

1. AtCoder Beginner Contest A–B.
2. Codeforces Div. 4 A–B.
3. Reach consistent A–C performance.
4. Upsolve D before increasing contest volume.

## Upsolve workflow

1. Retry for 20–30 minutes without contest pressure.
2. Classify the failure as knowledge, recognition, logic, implementation, or time management.
3. Request the lowest useful hint level.
4. Close the editorial and implement from a blank editor.
5. Record the missed signal and the corrected pattern.
6. Review again at D+7 and D+21.

Do not enter a new contest only to protect a streak while the previous contest still has valuable unresolved work.
